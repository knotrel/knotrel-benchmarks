# HDT collection: dense

This collection contains 128 isolated backend processes with
`knotrel-core/hdt-levels-v1`. The manifest records exact arguments, compiler,
sources, binary, commands, trace hashes and whole-process peak RSS.

See [analysis and limitations](../2026-09-28-hdt-v2-dense/README.md),
[per-process data](summary.csv) and [manifest](manifest.json).
Original/repeated query populations and setup are separate. These are synthetic
local observations, not production latency or market comparisons.
