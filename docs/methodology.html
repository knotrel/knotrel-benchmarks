METHODOLOGY

Numbers need context.

A reproducible comparison connects every estimate to its workload, environment and raw observations.

01 / Freeze the experiment

Pin candidate and reference revisions, binary hashes, backend, graph traces, seeds, resource budgets, warm-up, run order, sample counts, exclusions and analysis. Exploratory profiling does not enter the formal sample.

02 / Compare equivalent work

Match graph, lifecycle, visibility and atomicity semantics. Validate with an independent oracle. Measure all required work; classify incompatible arms as NOT_EQUIVALENT.

03 / Quantify uncertainty

Use independent repeated process runs and balanced or randomized ordering. Report 95% confidence intervals for absolute estimates and changes where supported, with the estimand, method and run count. Preserve paired designs and account for correlated observations.

A p99 describes a latency tail; its confidence interval describes uncertainty in that estimate. Millions of requests in one process are not millions of independent experiments. Deterministic byte counts need no artificial interval. Missing intervals require an explanation.

04 / Interpret the whole system

Show latency with successful throughput, errors and offered load; CPU with work completed; memory with process boundaries; feeder responses with freshness. Declare open-loop or closed-loop load and avoid coordinated omission.

05 / Preserve unfavorable results

Keep failed and invalid runs. Thresholds, multiple-comparison policy and rerun rules are declared in advance. Report practical effect sizes and uncertainty; statistical significance alone is not a regression budget.

PASS / FAIL / REGRESSION

Campaign-defined verdicts, not recalculated by this website. A qualifier such as PASS (IMPROVED) is kept as written.

INCONCLUSIVE / UNRESOLVED / INVALID

Insufficient precision (including INCONCLUSIVE_DISCLOSED) or invalid evidence must remain visible.

NOT_EQUIVALENT

A contract mismatch cannot establish a comparative performance claim.

TIMER_LIMITED / EXCEEDS_BUDGET

A timer-limited cell or a disclosure category is listed with its numbers, never converted.

NOT_RUN / no verdict

Unmeasured or nonconforming results show their reason and no numbers.
